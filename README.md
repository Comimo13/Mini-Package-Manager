# Simple Python Package Manager

A small educational project that simulates a basic package manager in Python.

## 📦 Features
- Install modules (`install`)
- Remove modules (`remove`)
- Check installed packages

## ⚙️ How it works
Packages are stored locally in the `Functions` folder  
and copied into `Functions/Modules` when installed.

## 🚀 Usage

```bash
python main.py api install plus
python main.py api remove plus
